HyperOS Toolkit: fix delayed notifications, remove bloatware & ads on Xiaomi HyperOS, and swap Xiao AI for Gemini, ChatGPT or Claude

Android 8+Xiaomi · Redmi · POCONo rootEnglish · Tiếng Việt

Zalo, Messenger, Gmail, Telegram or WhatsApp notifications arrive late, or only when you open the app? HyperOS freezes apps and Google Play Services in the background to save battery. HyperOS Toolkit (formerly HyperNotifyFix) finds what is blocking your notifications and fixes it, without root, through Shizuku.

What it does

  • Turns off battery optimization (Doze) and background limits for the apps you pick
  • Adds them to Xiaomi’s hidden MILLET and low-latency whitelists, refreshes MiPush and reconnects Google push (FCM)
  • Every change is previewed, backed up and reversible. Dry Run is on by default
  • AI assistant on the power button: replace Xiao AI with Gemini, ChatGPT, Claude or any installed assistant. After the first setup you can switch without Shizuku
  • Tools tab: remove bloatware and system ads (MSA, Analytics, GetApps, preinstalled Chinese apps), restorable with one tap; change the locked default browser or launcher
  • Bank-safe mode: when you are done, one tap turns Developer options and debugging off so banking apps open normally, and every fix stays
  • Keeps every fix after a reboot and after HyperOS rewrites it (HyperOS China resets the assistant on every boot)
  • Tested on Xiaomi 15 Ultra (HyperOS 3). Other HyperOS / MIUI phones should work: please report your results

How to install

  1. Download HyperOS-Toolkit-<version>.apk and install it (allow “Install unknown apps” if asked).
  2. Install Shizuku from Google Play.
  3. Settings → About phone → tap OS version 7 times. Then Additional settings → Developer options → turn on Wireless debugging.
  4. Open Shizuku → Start via Wireless debugging → pair with the code → Start.
  5. Open HyperOS Toolkit → allow Shizuku → pick the apps with late notifications → Run diagnostics → turn off Dry Run → Apply.
  6. Optional: Settings → Power-key AI assistant → pick Gemini, ChatGPT, Claude… → Apply. Bloatware and ads: Tools tab.
  7. Done? Tools → Turn off now (bank-safe mode) so banking apps work again.

Battery use may rise slightly. No app can guarantee instant notifications: the sender’s server and your network matter too.

ConvertApp: free offline file converter for Windows, Mac & Linux

Windows 10/11macOSLinuxEnglish · Tiếng Việt

Convert many files at once without uploading them to some website. Drag files in, pick a format, done. On Windows, just right-click files → Convert to ▸.

What it does

  • Images: PNG, JPG, WebP, GIF, BMP, TIFF, ICO, SVG, with resize, quality and EXIF auto-rotate
  • Merge many images into one PDF or one long picture
  • Documents: Markdown ↔ HTML, Markdown/HTML → Word or PDF, Word → Markdown/HTML, web page → PDF or full-page PNG
  • Office: Word, Excel, PowerPoint (DOCX, XLSX, PPTX, ODT…) → PDF and between Office formats

How to install

WindowsYour system
ConvertApp_…_x64-setup.exe
SmartScreen warning? More info → Run anyway.
macOSYour system
…_aarch64.dmg (Apple M chip) or …_x64.dmg (Intel)
Drag to Applications, then right-click → Open.
LinuxYour system
.deb (Ubuntu/Debian) or .AppImage
chmod +x the AppImage, then run it.

Images, Markdown and HTML work right away. For Word, PDF and Office the app tells you which free tool to install (Pandoc, LibreOffice, or Edge/Chrome).

Kell Auto Clicker: free auto clicker & macro recorder

WindowsmacOSLinuxJava included

Stop doing the same clicks over and over. Record mouse clicks, key presses, scrolls and drag-and-drops once, then replay them as many times as you want.

What it does

  • Global hotkeys: F9 record, F7 play, F8 stop, even while another app is in front
  • Add steps by hand: click a point, press keys, scroll, drag-and-drop, comments
  • Repeat N times or for a set duration, with natural random mouse paths
  • Save and load macros. Nothing else to install

How to install

WindowsYour system
.msi, or auto-clicker-windows-portable.zip (no install)
SmartScreen warning? More info → Run anyway.
macOSYour system
.dmg: arm64 (Apple M chip) or x64 (Intel)
Right-click → Open, then allow it in Privacy & Security → Accessibility.
LinuxYour system
.deb or .tar.gz
Global hotkeys need an X11 session (not Wayland).
